# n8n Contact Form Automation

## 📌 Project Overview
This project is an automated contact form handling system built using **n8n**.  
It captures form submissions via webhook, processes data conditionally, stores it in Google Sheets, sends email notifications, and responds back to the user automatically.

## 🚀 Features
- Webhook-based contact form integration
- Conditional logic using IF node
- Data processing using Edit Fields
- Merge logic for multiple flows
- Stores submissions in Google Sheets
- Sends automated email notifications
- Responds to user with success message

## 🛠 Tools & Technologies
- n8n (Workflow Automation)
- Webhooks
- Google Sheets API
- Gmail / Email node
- JSON-based workflow export

## 📂 Files
- `contact form Automation-v1.json` – n8n workflow export file

## 🔁 Workflow Logic
1. Webhook receives form data
2. Conditions applied using IF node
3. Data formatted using Edit Fields
4. Merged flow processed
5. Data appended to Google Sheet
6. Email notification sent
7. User receives automated response

## 🎯 Use Case
This automation can be used in:
- Company contact forms
- Support request handling
- Internship / career inquiries
- Lead collection systems

## 📌 How to Use
1. Import the JSON file into n8n
2. Configure credentials (Google Sheets, Email)
3. Activate the workflow
4. Use the webhook URL in your contact form
